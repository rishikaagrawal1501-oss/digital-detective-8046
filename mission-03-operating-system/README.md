### Task 3.2 – Understand Processes

**1. What is a process?**

A process is a program that is currently running on a computer. It uses system resources such as CPU and memory to perform tasks.

**2. What does the PID column represent?**

PID stands for Process ID. It is a unique identification number assigned to each running process by the operating system.

**3. Give two examples of processes that may be running on your computer.**

- Google Chrome – A browser process used to access websites.
- Visual Studio Code – A process used for writing and editing code.


### Task 3.3 – Understand Paths and Permissions

**1. Absolute Path:**

An absolute path is the complete location of a file or folder starting from the root directory (/).

Example: /Users/username/digital-detective-8046/mission-03-operating-system

**2. Relative Path:**

A relative path specifies the location of a file or folder from the current working directory.

Example: mission-03-operating-system/README.md

| Permission | Meaning | Example |
|---|---|---|
| r – Read | Allows a file's contents to be read. | Opening a text file. |
| w – Write | Allows a file to be modified. | Editing a text file. |
| x – Execute | Allows a file to be executed. | Running a script. |


### Task 3.4 – Explain Operating System Responsibilities

| OS responsibility | Your explanation | Example |
|---|---|---|
| Process management | Manages running programs and allocates CPU time to them. | Running Google Chrome and VS Code together. |
| Memory management | Allocates and manages RAM for different programs. | Giving memory to a browser while it is running. |
| Device management | Controls and manages hardware devices connected to the computer. | Managing keyboard, mouse and printer. |
| File management | Organizes, stores, retrieves and manages files and folders. | Creating, deleting and renaming files. |
| User interface / shell | Allows users to interact with the computer through graphical or command-line interfaces. | Using Terminal to execute commands. |
| Security and permissions | Protects system resources and controls access to files and applications. | Using passwords and file permissions. |
