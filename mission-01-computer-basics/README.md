
# Mission 1 – Know Your Computer

## Task 1.1 – Trace One Activity Using IPOS

### Activity: Typing and Saving a Document

A computer follows four stages when I type and save a document.

| Stage | What happens in my example? | Possible hardware / component |
|---|---|---|
| Input | I type text using the keyboard. | Keyboard |
| Processing | The CPU processes the entered text. | CPU and Memory |
| Output | The typed text appears on the screen. | Monitor |
| Storage | I save the document on my laptop. | SSD |

### Explanation

When I type a document, the keyboard takes input. The CPU processes the information, and the screen displays the text. Finally, the document is saved in the laptop's storage for future use.



## Task 1.2 – Identify Hardware and Software

### Hardware and Software Examples

| Item / Software Name | Hardware or Software? | Software Type | Purpose |
|---|---|---|---|
| Keyboard | Hardware | Not applicable | Used to enter text |
| Mouse / Trackpad | Hardware | Not applicable | Used to control the pointer |
| Monitor | Hardware | Not applicable | Displays information |
| SSD | Hardware | Not applicable | Stores files and data |
| macOS | Software | Operating System | Manages computer resources |
| Visual Studio Code | Software | Application Software | Used to write and edit code |
| Google Chrome | Software | Application Software | Used to browse the internet |
| Disk Utility | Software | Utility Software | Helps manage storage disks |

### Explanation

Hardware refers to the physical components of a computer that we can touch.

Software refers to programs and instructions that tell the computer what to do.
