
## Task 6.1 — Understand the Basic Git Workflow

### 1. Check Repository Status

Command:
`git status`

Explanation:
This command shows the current branch and tells us which files are modified, staged, or untracked.

### 2. Stage Selected Changes

Command:
`git add README.md`

Explanation:
This command stages the selected README file so that its changes are ready to be included in the next commit.

### 3. Create a Commit

Command:
`git commit -m "Complete Git workflow task"`

Explanation:
This command saves the staged changes as a commit in the Git repository with a meaningful message.

### 4. View Commit History

Command:
`git log --oneline`

Explanation:
This command displays the recent commit history in a short and readable format.

### Difference Between Staging and Committing

Staging means selecting and preparing changes that we want to save. Committing means recording those staged changes in the repository's history.

### Learning Outcome

I learned how Git tracks changes, how to stage selected files, how to create commits, and how to inspect the commit history.
